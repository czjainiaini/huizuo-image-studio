# 绘作台 · Qwen Image 2.1

原生ComfyUI图片生成与编辑工作流，当前版本 **0.4.4研究评估版**。

文生图、单图编辑、2–4图融合使用中文任务入口。内置15个中文提示词示例、可选结构助手、主画布AI提示词优化开关，以及可选LoRA管理版。PE默认关闭；普通出图不依赖额外PE模型。新版流程的上传参考图和生成预览存放在服务进程内存中，平台完整关机后释放，模型与设置保留。

本仓库提供工作流、原创节点及侧栏代码、固定依赖安装脚本和Docker构建文件。AutoDL保存的镜像仍由平台管理，不存放在Git仓库里。应用公开上架及创作者激励需要另行处理平台审核和模型商业授权。

## 使用入口

- [镜像启动与使用指南](使用指南.md)：平台开机 → 6006 → 等待准备 → 选择工作流 → 下载需要的结果 → 平台关机。
- [中文提示词示例与AI优化](提示词示例.md)：示例先预览再采用；可选PE关闭时直接使用原始提示词。
- [LoRA使用说明](LoRA使用说明.md)：管理器默认关闭、列表为空，模型兼容性需要核对。
- [部署说明](deploy/README.md)：在已有Linux实例装配，或构建Docker镜像。
- [AutoDL源码关联说明](AutoDL发布说明.md)：仓库地址、镜像和平台发布的关系。

如果已经获得维护者提供的AutoDL镜像，在自己实例的入口点6006；AutoDL控制台也可能将该按钮称为“自定义服务”。6008没有配置服务。无卡模式可自动准备缺失核心模型并打开界面，GPU模式才能生成图片或执行官方PE优化。

## 工作流文件

| 文件 | 功能 |
| --- | --- |
| `workflows/00-绘作台-整合版.json` | 三种任务的整合入口 |
| `workflows/01-文生图.json` | 文生图 |
| `workflows/02-单图编辑.json` | 单图编辑 |
| `workflows/03-多图融合.json` | 多图融合 |
| `workflows/10-可选提示词优化-文生图.json` | 独立文生图提示词优化预览 |
| `workflows/11-可选提示词优化-编辑.json` | 独立编辑提示词优化预览 |
| `workflows/20-绘作台-LoRA管理版.json` | 可选LoRA管理器与触发词预览 |

普通四份生成画布无需LoRA插件。管理版需要安装固定ComfyUI-LoRA-Manager；Docker构建时显式使用 `WITH_LORA_MANAGER=1`。主画布的AI优化节点默认关闭，开关同时可从侧栏操作。

## 模型准备

核心三份权重合计约17.28GB。启动先检查已有文件、尝试平台公共模型，缺失时下载并核对固定修订、大小与SHA256。公共挂载链接不可用时会进入下载路径；首次启动需要网络和磁盘空间，不能保证立即出图。

PE文生图和编辑权重各约9.47GB，默认不下载。只准备需要的一份即可，模型文件与用户结果不收入此仓库。空间不足时会停止，不自动付费扩容。

## 已验证范围

在4080(S)32GB／50GB私人研究实例上，文生图7画幅×3尺寸×3步数共63组、编辑4预算×1–4图共16组均执行成功。15个中文示例、9个快捷提示、8个PE对照和8个LoRA对照已执行留证。

0.4.4私人镜像恢复后，普通三类出图在缺少PE权重且开关关闭时通过；实际平台关机、无卡自动重启后，原上传和生成链接失效，图片目录为空，核心模型及启动设置保留。Windows输入法候选选择与退格由用户真实操作验证。

部分原始示例仍有额外文字、背景参考混入、姿势精度等限制；PE开启不一定改善结果。完整范围、定向复测与未测试边界见[补漏验收结果](evidence/v044-complete-validation.md)。本地Docker完成CUDA构建和CPU界面检查，未把本机4GB显卡测试冒称Qwen GPU推理验收。
